# Next Permutation

## Problem Statement
Given a collection of distinct integers, return all possible permutations of the collection where a permutation is a sequence of all integers in the collection. The next permutation of an array of integers is generated by a specific rule: if the current permutation is in ascending order, the next permutation will be the first permutation in lexicographical order. Otherwise, find the first pair of two successive elements that are in descending order, reverse the sub-array after the first element, and then find the smallest element greater than the first element in the reversed sub-array. If no such pair is found, the next permutation is the first permutation in lexicographical order. For example, the next permutation of [1,2,3] is [1,3,2], and the next permutation of [3,2,1] is [1,2,3]. The function should take an array of integers as input and output the next permutation of the array.

## Approach
The algorithm generates the next permutation of an array by finding the first pair of two successive elements in descending order, then reversing the sub-array after the first element and finding the smallest element greater than the first element to swap. If no such pair is found, the array is reversed to get the first permutation. This approach ensures that the next permutation is generated in lexicographical order.

## Complexity
- Time: O(n)
- Space: O(1)

## C++ Solution
```cpp
#include <bits/stdc++.h>
using namespace std;

void nextPermutation(vector<int>& nums) {
    int i = nums.size() - 2;
    // find the first pair of two successive elements in descending order
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }
    // if no such pair is found, the array is the last permutation
    if (i >= 0) {
        int j = nums.size() - 1;
        // find the smallest element greater than the first element
        while (nums[j] <= nums[i]) {
            j--;
        }
        // swap the first element and the smallest element greater than it
        swap(nums[i], nums[j]);
    }
    // reverse the sub-array after the first element
    reverse(nums.begin() + i + 1, nums.end());
}

int main() {
    vector<int> nums = {1, 2, 3};
    nextPermutation(nums);
    for (int num : nums) {
        cout << num << " ";
    }
    return 0;
}
```

## Key Takeaways
- The algorithm iterates through the array from right to left to find the first pair of two successive elements in descending order.
- The smallest element greater than the first element is found by iterating through the array from right to left.
- The sub-array after the first element is reversed to generate the next permutation in lexicographical order.
