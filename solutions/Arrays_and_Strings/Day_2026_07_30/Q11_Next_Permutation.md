# Next Permutation

## Problem Statement
Given a collection of distinct integers, return all possible permutations of the collection. The next permutation of an array of integers is generated by a specific rule: if the current permutation is in ascending order, then the next permutation will be the first permutation in lexicographical order; if the current permutation is in descending order, then the next permutation will not exist. For example, the next permutation of [1, 2, 3] is [1, 3, 2], and the next permutation of [3, 2, 1] is [1, 2, 3]. The array is 1-indexed, and the next permutation should be in-place.

## Approach
The algorithm involves finding the first decreasing element from the right, then swapping it with the smallest element greater than it on its right, and finally reversing the elements on the right of the swapped element. This approach ensures that the next permutation is generated in lexicographical order.

## Complexity
- Time: O(n)
- Space: O(1)

## C++ Solution
```cpp
#include <bits/stdc++.h>
using namespace std;

void nextPermutation(vector<int>& nums) {
    // Find the first decreasing element from the right
    int i = nums.size() - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }
    
    // If the array is in descending order, reverse it
    if (i >= 0) {
        int j = nums.size() - 1;
        while (nums[j] <= nums[i]) {
            j--;
        }
        swap(nums[i], nums[j]);
    }
    
    // Reverse the elements on the right of the swapped element
    int left = i + 1;
    int right = nums.size() - 1;
    while (left < right) {
        swap(nums[left], nums[right]);
        left++;
        right--;
    }
}

int main() {
    vector<int> nums = {1, 2, 3};
    nextPermutation(nums);
    for (int num : nums) {
        cout << num << " ";
    }
    return 0;
}
```

## Key Takeaways
- The next permutation of an array can be generated by finding the first decreasing element from the right and swapping it with the smallest element greater than it on its right.
- Reversing the elements on the right of the swapped element ensures that the next permutation is generated in lexicographical order.
- The time complexity of the algorithm is O(n), where n is the size of the input array, and the space complexity is O(1) since the algorithm only uses a constant amount of space.
