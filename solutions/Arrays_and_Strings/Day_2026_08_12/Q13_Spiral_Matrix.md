# Spiral Matrix

## Problem Statement
Given an integer `n`, generate a spiral matrix of size `n x n` filled with numbers from 1 to `n * n` in a spiral pattern, starting from the top left and moving clockwise. The input will be a positive integer `n`, and the output should be a 2D vector representing the spiral matrix. For example, if `n = 3`, the output should be `[[1, 2, 3], [8, 9, 4], [7, 6, 5]]`. If `n = 4`, the output should be `[[1, 2, 3, 4], [12, 13, 14, 5], [11, 16, 15, 6], [10, 9, 8, 7]]`.

## Approach
The algorithm starts by initializing the matrix with zeros and then filling it in a spiral pattern by maintaining four pointers (top, bottom, left, right) to keep track of the current boundaries. We iterate through the numbers from 1 to `n * n`, placing each number in the matrix according to the current direction (right, down, left, up).

## Complexity
- Time: O(n^2)
- Space: O(n^2)

## C++ Solution
```cpp
#include <vector>
using namespace std;

vector<vector<int>> generateMatrix(int n) {
    vector<vector<int>> matrix(n, vector<int>(n, 0));
    int top = 0, bottom = n - 1, left = 0, right = n - 1;
    int num = 1;
    while (top <= bottom && left <= right) {
        // Fill from left to right
        for (int i = left; i <= right; i++) {
            matrix[top][i] = num++;
        }
        top++;

        // Fill from top to bottom
        for (int i = top; i <= bottom; i++) {
            matrix[i][right] = num++;
        }
        right--;

        // Fill from right to left
        if (top <= bottom) {
            for (int i = right; i >= left; i--) {
                matrix[bottom][i] = num++;
            }
            bottom--;
        }

        // Fill from bottom to top
        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                matrix[i][left] = num++;
            }
            left++;
        }
    }
    return matrix;
}
```

## Key Takeaways
- The spiral matrix can be generated by maintaining four pointers to keep track of the current boundaries.
- The algorithm iterates through the numbers from 1 to `n * n`, placing each number in the matrix according to the current direction.
- The time complexity is O(n^2) because we are filling in the matrix once, and the space complexity is also O(n^2) because we are storing the matrix.
