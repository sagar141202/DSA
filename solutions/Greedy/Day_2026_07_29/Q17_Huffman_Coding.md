# Huffman Coding

## Problem Statement
Huffman coding is a lossless data compression algorithm. The problem statement is to assign variable-length binary codes to input characters such that the more frequently a character appears, the shorter its binary code will be. The goal is to minimize the total length of the encoded string. Given a string, we need to find the Huffman codes for each character and return the encoded string.

## Approach
The algorithm uses a priority queue to store characters and their frequencies. It repeatedly removes the two nodes with the lowest frequencies, combines them into a new node, and adds the new node back into the queue. This process continues until only one node is left, which is the root of the Huffman tree.

## Complexity
- Time: O(n log n)
- Space: O(n)

## C++ Solution
```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    char character;
    int frequency;
    Node* left;
    Node* right;

    Node(char character, int frequency) {
        this->character = character;
        this->frequency = frequency;
        this->left = nullptr;
        this->right = nullptr;
    }
};

struct compare {
    bool operator()(const Node* a, const Node* b) {
        return a->frequency > b->frequency;
    }
};

string huffmanEncoding(string text) {
    // Calculate frequency of each character
    unordered_map<char, int> frequency;
    for (char c : text) {
        frequency[c]++;
    }

    // Create a priority queue to store nodes
    priority_queue<Node*, vector<Node*>, compare> pq;
    for (auto& pair : frequency) {
        Node* node = new Node(pair.first, pair.second);
        pq.push(node);
    }

    // Build the Huffman tree
    while (pq.size() > 1) {
        Node* left = pq.top();
        pq.pop();
        Node* right = pq.top();
        pq.pop();

        Node* newNode = new Node('\0', left->frequency + right->frequency);
        newNode->left = left;
        newNode->right = right;

        pq.push(newNode);
    }

    // Generate Huffman codes
    unordered_map<char, string> codes;
    function<void(Node*, string)> generateCodes = [&](Node* node, string code) {
        if (node == nullptr) return;
        if (node->left == nullptr && node->right == nullptr) {
            codes[node->character] = code;
        }
        generateCodes(node->left, code + "0");
        generateCodes(node->right, code + "1");
    };
    generateCodes(pq.top(), "");

    // Encode the string
    string encodedString;
    for (char c : text) {
        encodedString += codes[c];
    }

    return encodedString;
}

int main() {
    string text = "this is an example for huffman encoding";
    string encodedString = huffmanEncoding(text);
    cout << "Encoded string: " << encodedString << endl;
    return 0;
}
```

## Key Takeaways
- Huffman coding is a lossless data compression algorithm that assigns variable-length binary codes to input characters based on their frequencies.
- The algorithm uses a priority queue to build the Huffman tree, which is a binary tree where each leaf node represents a character and its frequency.
- The Huffman codes are generated by traversing the Huffman tree and assigning a binary code to each character based on its position in the tree.
